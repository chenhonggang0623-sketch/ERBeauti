# ERBeauti「动态配置数据源」UI 设计文档

> 角色：UIUX 设计师  
> 目标：为 ERBeauti 新增「数据源配置」功能提供可落地的界面设计方案，确保与现有 Tailwind + 自定义组件设计系统保持一致。

---

## 1. 数据源配置入口位置建议

### 推荐方案：Header「导入」下拉菜单内新增入口 + Command Palette 命令

理由：
- 当前 Header 的「导入」下拉已承载 SQL / DBML / Prisma 三种文本导入方式，「从数据库连接导入」与现有导入语义最接近，用户心智一致。
- 数据源配置本身不是高频常驻操作，无需在 Header 上独占一个按钮，避免顶栏过度拥挤。
- 同时补充 Command Palette（Ctrl+K）命令，满足高级用户键盘直达诉求。

### 具体入口

1. **Header 导入 Dropdown**
   - 在「导入 SQL / DBML / Prisma」下方增加一条分隔线，再新增：
     - **从数据库连接导入**（图标：`Database`）
     - **管理数据源**（图标：`Settings2` 或 `Server`）
   - 若当前无任何已保存连接，「从数据库连接导入」可置灰或点击后先提示创建。

2. **Command Palette**
   - 新增 `datasource-manage` 命令：`管理数据源`（分组：数据源）
   - 新增 `datasource-import` 命令：`从数据库连接导入`（分组：数据源）

3. **Sidebar（可选增强）**
   - 不建议作为首要入口。数据源管理与当前表/字段浏览场景差异较大，放入 Sidebar 会稀释侧栏信息密度。如后续需要频繁切换连接，可在 Sidebar 折叠态增加一个「数据源」图标入口作为快捷方式。

### 入口层级示意

```
Header
├─ Logo
├─ 操作区
│  ├─ [导入 ▼]
│  │  ├─ 导入 SQL
│  │  ├─ 导入 DBML
│  │  ├─ 导入 Prisma
│  │  ├─ ──────────  分隔线
│  │  ├─ 从数据库连接导入   ← 新入口
│  │  └─ 管理数据源         ← 新入口
│  ├─ 重新布局
│  ├─ [导出 ▼]
│  └─ 主题 / 快捷键提示
```

## 2. 数据源管理弹窗/面板线框图

### 整体结构

采用与 `ImportDialog` 一致的**居中模态弹窗**，固定宽度，最大高度限制，保证视觉与交互习惯统一。

```
┌─────────────────────────────────────────────────────────────┐
│  [Server] 数据源配置                                    [X]   │  ← Header 标题栏
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ [数据库图标]  生产 MySQL          [测试] [编辑] [删除]│   │  ← 列表项 1
│  │ mysql://***@db.example.com:3306/erp        [● 正常] │   │
│  └─────────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ [数据库图标]  本地 Postgres       [测试] [编辑] [删除]│   │  ← 列表项 2
│  │ postgresql://***@localhost:5432/test       [● 未测] │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│           [+ 新建数据源]                                     │  ← 底部新建按钮
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 布局说明

| 区域 | 说明 |
|------|------|
| 标题栏 | 左侧图标 + 标题「数据源配置」，右侧关闭按钮（ghost icon）。 |
| 列表区 | 垂直滚动，每项为圆角卡片，hover 态背景变化。 |
| 空状态 | 无连接时居中展示 `Database` 图标 + 文案「暂无数据源」+「新建数据源」按钮。 |
| 底部操作 | 左下角「新建数据源」主按钮；右下角「关闭」按钮。 |

### 尺寸建议

- 弹窗宽度：`max-w-2xl`（约 672px），与 `TableEditDialog` 一致。
- 最大高度：`max-h-[85vh]`。
- 列表项内边距：`p-4`。
- 列表项间距：`space-y-3`。

## 3. 新增/编辑数据源表单设计

### 弹窗形态

点击「新建数据源」或列表项「编辑」后，**在同一弹窗内切换视图**（而非再叠加一层模态），减少层级与返回成本。左侧/顶部保留返回按钮，可回到列表。

### 表单结构

```
┌─────────────────────────────────────────────────────────────┐
│  [←] [数据库图标] 新建数据源                            [X]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  连接名称 *                                                 │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 生产 MySQL                                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  数据库类型 *                                               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ [MySQL ▼]                                           │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  连接方式                                                   │
│  ┌─────────────────┬────────────────────────────────────┐  │
│  │ ● URL 连接       │  分字段输入                        │  │
│  └─────────────────┴────────────────────────────────────┘  │
│                                                             │
│  连接 URL                                                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ mysql://user:pass@host:3306/db                      │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌──────────┐                                               │
│  │ 测试连接  │                                               │
│  └──────────┘                                               │
│                                                             │
│  [取消]              [保存]                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 连接名称 | Input | 是 | 用户自定义别名，如「生产 MySQL」。 |
| 数据库类型 | Select/Dropdown | 是 | MySQL / PostgreSQL / SQL Server / SQLite 等，决定方言与默认端口。 |
| 连接方式 | Segmented Control | 是 | 单选：「URL 连接」/「分字段输入」。 |
| URL | Input/Textarea | URL 方式必填 | 完整连接字符串，密码部分输入时显示。 |
| Host | Input | 分字段方式必填 | |
| Port | Input (number) | 分字段方式必填 | 根据数据库类型自动填充默认值（MySQL 3306、Postgres 5432）。 |
| 用户名 | Input | 否 | |
| 密码 | Input (password) | 否 | 脱敏显示，支持显示/隐藏切换。 |
| 数据库 | Input | 否 | 默认数据库名。 |

### 分字段输入布局

```
┌───────────────────────┬───────────────────────┐
│ Host *                │ Port *                │
│ localhost             │ 3306                  │
├───────────────────────┴───────────────────────┤
│ 用户名                                      │
│ root                                        │
├───────────────────────┬───────────────────────┤
│ 密码                    │ 数据库                │
│ ********                │ erp                   │
└───────────────────────┴───────────────────────┘
```

### 连接方式切换说明

- 使用**分段选择器（Segmented Control）**，两个选项等宽，选中项带蓝色背景。
- 切换时保留已输入字段的交集数据（如 host/port/username 与 URL 互相解析同步），避免用户重复输入。
- 切换时若字段值无法解析，清空目标区域并给出 subtle 提示。

### 操作按钮

- 底部左侧：「取消」（secondary）返回列表。
- 底部右侧：「保存」（primary），保存前不强制要求测试通过，但测试失败时二次确认提示。
- 表单中部：「测试连接」按钮（secondary/ghost），独立于保存流程。

## 4. 数据源列表项设计

### 单条列表项结构

```
┌────────────────────────────────────────────────────────────────────────────┐
│  ┌────────┐                                                                │
│  │  [DB]  │  生产 MySQL                              [测试] [编辑] [删除]  │
│  │  icon  │  mysql://***@db.example.com:3306/erp    [● 正常]              │
│  └────────┘                                                                │
└────────────────────────────────────────────────────────────────────────────┘
```

### 元素说明

| 元素 | 说明 |
|------|------|
| 数据库类型图标 | 根据 dialect 显示不同颜色图标：`Database` 基础图标 + 类型徽标或色点。 |
| 连接名称 | `text-sm font-semibold text-neutral-900 dark:text-neutral-100`，单行截断。 |
| 连接摘要 | `text-xs text-neutral-500`，脱敏后的 URL 或 `user@host:port/db`。 |
| 状态徽标 | 圆点 + 文字（见第 5 节），位于摘要右侧或单独一行。 |
| 操作按钮组 | 测试（ghost icon）、编辑（ghost icon）、删除（danger icon）。 |

### 脱敏显示规则

- URL 模式：将 `username:password` 中的 `password` 替换为 `***`，例如 `mysql://root:***@localhost:3306/erp`。
- 分字段模式：摘要显示为 `root@localhost:3306/erp`，密码永远不显示。
- 连接名称与数据库类型始终可见。

### 状态徽标位置

优先放在**连接摘要右侧**，在小屏或长 URL 时自动换行到第二行左侧。徽章与摘要间距 `gap-2`。

### Hover 与焦点

- 列表项 hover：`bg-neutral-50 dark:bg-neutral-800/60`，操作按钮由半透明变为完全不透明。
- 当前正在编辑/选中的连接：`ring-1 ring-blue-500/30 bg-blue-50/50 dark:bg-blue-900/20`。
- 操作按钮单独聚焦时显示 `focus:ring-blue-500`。

## 5. 连接测试的反馈设计

### 状态枚举与视觉

| 状态 | 颜色 Token | 图标 | 文案示例 | 说明 |
|------|------------|------|----------|------|
| 未测试 | neutral-400 | `Circle` 空心 | 未测试 | 初始或编辑后未重新测试。 |
| 测试中 | blue-600 | `Loader2` 旋转 | 连接中... | 按钮进入 loading 态，列表项徽标同步旋转。 |
| 成功 | emerald-500 | `CheckCircle2` | 连接成功 | 成功提示 2s 后自动恢复为「正常」。 |
| 失败 | red-500 | `XCircle` | 连接失败 | 显示具体错误信息。 |

### 测试流程交互

1. 用户点击「测试连接」。
2. 按钮进入 loading 态：`disabled` + `Loader2` 旋转图标 + 文案变「连接中...」。
3. 列表项状态徽标同步更新为蓝色旋转图标。
4. 结果返回后：
   - **成功**：按钮短暂显示绿色勾选 +「连接成功」，列表徽标变 emerald 圆点；2s 后按钮恢复默认「测试连接」。
   - **失败**：按钮恢复默认态，列表徽标变 red 圆点；在表单下方或列表项下方展开错误信息条。

### 错误反馈条设计

```
┌─────────────────────────────────────────────────────────────┐
│  [XCircle] 连接失败：Access denied for user 'root'           │
│  请检查用户名、密码及 host 是否允许远程访问。                 │
└─────────────────────────────────────────────────────────────┘
```

- 背景：`bg-red-50 dark:bg-red-900/20`
- 边框：`border border-red-200 dark:border-red-800`
- 文字：`text-sm text-red-700 dark:text-red-300`
- 图标：`h-4 w-4 text-red-500`
- 内边距：`p-3 rounded-md`

### Toast 反馈

- 成功：全局 `toast.success('连接成功')`。
- 失败：全局 `toast.error('连接失败：具体原因')`。

## 6. 逆向生成 ER 图的触发流程设计

### 入口 A：从 Header「导入」下拉进入

1. 用户点击「从数据库连接导入」。
2. 打开「数据源选择 + 逆向生成」弹窗。
3. 弹窗上半部分列出已保存连接，用户单选其中一个。
4. 选中后显示该连接摘要与上次测试状态。
5. 点击「生成 ER 图」按钮后：
   - 先自动执行一次连接测试。
   - 连接成功后调用后端/本地服务获取 schema。
   - 关闭弹窗，进入 `layoutLoading` 状态，画布显示 `LoadingOverlay`。
   - 生成完成后 toast 提示「已生成 ER 图，共 X 张表」。

### 入口 B：从「数据源管理」弹窗进入

1. 在数据源列表项上增加「生成 ER 图」按钮（图标：`ArrowRight` 或 `Sparkles`）。
2. 点击后弹出二次确认：
   - 标题：使用「生产 MySQL」生成 ER 图？
   - 内容：将读取该数据库的表结构并覆盖当前画布内容。
   - 按钮：「取消」/「确认生成」。
3. 确认后进入入口 A 的生成流程。

### 生成确认弹窗

```
┌─────────────────────────────────────────────────────────────┐
│  [Sparkles] 生成 ER 图                                  [X]   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  将使用以下连接读取数据库表结构：                             │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ [DB] 生产 MySQL                                     │   │
│  │ mysql://***@db.example.com:3306/erp                 │   │
│  │ 状态：● 正常                                        │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  当前画布内容将被覆盖，是否继续？                           │
│                                                             │
│              [取消]            [确认生成]                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 空连接处理

- 若用户点击「从数据库连接导入」但无已保存连接：
  - 直接打开「新建数据源」表单。
  - 底部提示「还没有数据源？先创建一个」。

## 7. 深色模式适配说明

整体遵循项目已有的 `dark:` 前缀方案，所有新增组件需补充完整深色 Token。

### 弹窗容器

- 浅色：`bg-white border-neutral-200`
- 深色：`dark:bg-neutral-900 dark:border-neutral-700`

### 列表项

- 默认背景：`bg-white dark:bg-neutral-900`
- hover：`hover:bg-neutral-50 dark:hover:bg-neutral-800/60`
- 选中/编辑态：`bg-blue-50/50 dark:bg-blue-900/20 ring-blue-500/30`

### 表单输入

复用现有 `Input` / `Textarea` 组件，已自带深色样式：
- `dark:border-neutral-700 dark:bg-neutral-900 dark:text-neutral-100`
- placeholder：`placeholder:text-neutral-400`
- focus：`focus:border-blue-500 focus:ring-blue-500/20`

### 文字层级

| 层级 | 浅色 | 深色 |
|------|------|------|
| 主标题 | `text-neutral-900` | `dark:text-neutral-100` |
| 副标题/标签 | `text-neutral-500` | `dark:text-neutral-400` |
| 连接摘要 | `text-neutral-500` | `dark:text-neutral-400` |
| 错误信息 | `text-red-700` | `dark:text-red-300` |

### 按钮

复用 `Button` 组件，primary/secondary/ghost/danger 均已有深色适配。

### 图标

- 状态图标颜色在不同模式下保持一致语义色（如 emerald-500、red-500）。
- 操作图标使用 `text-neutral-400 hover:text-neutral-600 dark:text-neutral-500 dark:hover:text-neutral-300`。

### 无障碍

- 确保所有深色背景上的文字对比度 ≥ 4.5:1。
- focus 状态使用 `focus:ring-2 focus:ring-blue-500`。

## 设计原则总结

1. **一致性**：复用 `ImportDialog`、`TableEditDialog` 的弹窗尺寸、圆角、动画与色彩体系。
2. **渐进披露**：先展示列表，再进入表单，避免一次性暴露过多字段。
3. **安全感知**：密码全程脱敏，连接摘要脱敏显示，编辑时重置测试状态。
4. **即时反馈**：测试连接、生成 ER 图均有 loading / success / error 三态反馈。
5. **键盘友好**：通过 Command Palette 与按钮 focus 状态支持无鼠标操作。
